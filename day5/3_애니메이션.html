CSS Animation 실습장

페이지가 열리자마자 스스로 움직이는 요소들과 마우스 반응형 제어를 확인해 보세요.

1. 방향 제어: normal vs alternate (왕복)

normal은 끝까지 가면 처음으로 뚝 끊겨 돌아오지만, alternate는 공이 튀듯 부드럽게 왕복합니다.

normal
(뚝 끊김)
alternate
(부드러운 왕복)

2. 다단계 시나리오 (@keyframes 0% ~ 100% 세분화)

transition으로는 불가능한 구간별(0%, 33%, 66%, 100%) 다채로운 변화를 연속으로 실행합니다.

다단계 변화
(이동+색상+회전)

3. 종료 후 상태 고정 (animation-fill-mode: forwards) - 점선 영역에 마우스를 올리세요!

1회만 재생되는 애니메이션이 끝났을 때, 처음으로 돌아갈지(none) 도착 지점에 남을지(forwards) 비교해 보세요.

fill-mode: none
(끝나면 돌아감)
fill-mode: forwards
(도착 상태 유지!)

4. 로딩 스피너 & 일시정지 (animation-play-state)

돌아가는 원(로딩 아이콘)에 마우스를 올리면 일시정지(paused)되고, 떼면 다시 돕니다.

⬅ 회전하는 로딩 바에 마우스를 올려보세요!
